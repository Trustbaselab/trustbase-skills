# ✅ BOOK-TO-SKILL 检查清单（交付前逐项打勾）

> **用途**：每个新 skill 交付前，**逐项打勾**。全过才能上线。
> **⭐ 这是"可行性办法"的核心 —— 不靠人记，靠清单。**

---

## 一、⭐ 文件结构（5 项）

- [ ] **`<skill-name>/SKILL.md` 存在**
- [ ] **`<skill-name>/references/<book>-book.md` 存在**
- [ ] ⭐ **`<skill-name>/references/evidence.md` 存在**
- [ ] ⭐ **`<skill-name>/METHOD.md` 存在**（这本书的**具体**转化记录）
- [ ] **目录名 = `SKILL.md` 里的 `name`**

---

## 二、⭐ Frontmatter 合规（4 项）

- [ ] **`name` ≤ 64 字符**
- [ ] **`name` 全小写 + 连字符**（`^[a-z0-9-]+$`）
- [ ] **`name` = 目录名**
- [ ] **`description` ≤ 1024 字符，且包含：**
  - [ ] **做什么**（一句话）
  - [ ] ⭐ **全部触发条件**（具体词句）
  - [ ] ⭐ **不适用边界**（指向其他 skill）

---

## 三、⭐⭐ 内容质量（6 项）

- [ ] ⭐ **有"核心判断"**（作者在跟谁争论、争什么）
- [ ] ⭐ **有"何时使用 / 不适用"**
- [ ] ⭐ **规则是 if-then 形式**（**不是"要客观"这种口号**）
- [ ] ⭐ **每条规则有反例**（不这么做会怎样）
- [ ] **有输出格式**
- [ ] **篇幅合理**（8–20KB；过长说明塞了太多"道理"）

---

## 四、⭐⭐⭐ 验证（4 项）

- [ ] ⭐ **有真实场景**（什么项目、什么规模）
- [ ] ⭐ **有前后对比数字**（**不是"大幅减少"**）
- [ ] ⭐ **有数据口径说明**（哪些实测、哪些估算）
- [ ] ⭐⭐ **有四条诚实边界**：
  - [ ] **口径说明**
  - [ ] **归因限制**（"不是对照实验"）
  - [ ] **引用表述**（"验证案例"而非"因果证明"）
  - [ ] **未完成项**（"进行中"就写"进行中"）

---

## 五、⭐ 版权边界（4 项）

- [ ] ⛔ **没有大段引用原文**
- [ ] ✅ **注明"基于《书名》的理念"**
- [ ] ✅ **结尾有 `Based on: <book>. We license our translation, not the original.`**
- [ ] ✅ **`License: Apache-2.0`**

---

## 六、⭐ 与体系的关系（3 项）

- [ ] ⭐ **在 `cognitive/README.md` 的六层图里有位置**
- [ ] **`description` 里指向了相邻层的 skill**（避免重叠）
- [ ] **不和其他 skill 的触发条件冲突**

---

## 七、⭐ 实机验证（3 项）

- [ ] ⭐ **装进 agent 后能被触发**（说触发词，看它是否加载）
- [ ] ⭐ **触发后输出符合 SKILL.md 规定的格式**
- [ ] **不触发的场景不会误触发**

---

# ⭐⭐⭐ 评分卡（交付时打分）

| 维度 | 权重 | 得分（0-5） |
|---|---|---|
| **结构完整** | 20% | |
| **Frontmatter 合规** | 10% | |
| **内容质量（if-then）** | 25% | |
| ⭐ **验证（含诚实边界）** | 30% | |
| **版权边界** | 15% | |

**判定：**
- **≥ 4.5** → ✅ **上线**
- **3.5 – 4.4** → 🟡 **补强后上线**
- **< 3.5** → ⛔ **退回重做**

# ⭐ 常见错误（**踩过就记下来**）

| # | 错误 | 后果 | 修法 |
|---|---|---|---|
| **1** | **`name` ≠ 目录名** | **CLI 装不上** | **改目录名** |
| **2** | **`description` 没写不适用** | **误触发** | **加"不适用"段** |
| **3** | **规则是口号不是 if-then** | **agent 不知道怎么执行** | **改成"当 X 时做 Y"** |
| **4** | ⭐ **证据只有"大幅改善"** | **不可验证 = 没价值** | **换成具体数字** |
| **5** | ⭐ **缺"归因限制"** | ⭐ **变成虚假宣称** | **加一条"不是对照实验"** |
| **6** | **没写完的写成"已达成"** | ⭐ **诚实性崩塌** | **改"进行中"** |
| **7** | **大段抄原文** | **法律风险** | **改写成自己的理解** |
| **8** | **缺 `METHOD.md`** | **下一本无法复用** | **补上** |
