# rCB 价格参考估算

## 何时使用

- 询问 rCB 的价格水平或价格区间
- 拿一个报价来问「合理吗」
- 估算采购预算 / 做成本测算的输入
- 询问 rCB 与原生炭黑的价格关系（便宜多少 / 贵多少）

**不适用（转用其他 Skill）**：

- 判断能否替代某牌号 → 用 `rcb-substitution-assessment`
- 问出口合规 → 用 `rcb-export-compliance`

## 执行流程（四步）

### ① 先固定三个坐标，再取数

任何价格回答都必须先明确：

| 坐标 | 取值 | 为什么必须 |
|---|---|---|
| **层级** | P1 精制 / P2 标准 / P3 工业 | 不同层级锚定比差异明显，混在一起就是错的 |
| **区域** | CN / EU / NA / SEA | 区域系数含**合规溢价**，不是单纯物流汇率差 |
| **期别** | YYYY-MM | 锚本身月度波动较大，过期数会误导 |

**缺任何一个坐标，就先向用户确认或给出多组值——不要默认一个然后给单点数字。**

### ② 取锚定比与价差（`get_rcb_vcb_spread`）

得到原生炭黑锚价、rCB 参考价、价差与折扣率。

注意：**未通过发布门槛的组合会返回 null 并附原因**（例如某区域系数尚未校准）。此时**如实告知该项暂不可用**，不要用其他区域的数字替代。

### ③ 取指数与归因分解（`get_rcb_index`）

**必须区分两个因子**：

- **AF（锚因子）**：来自原生炭黑锚价的变动——高置信，可严格回溯
- **VF（价值因子）**：rCB 相对价值的加权变化——由驱动因子合成，**未经价格数据校准**

**不要把两者合并成一个「rCB 涨价了」的说法。** 若 VF 状态为 `not_assessed`，说明该期指数变动**全部来自锚**，必须如实说明。

## 硬约束（违反即判定为错误输出）

1. **只给参考区间，不给单点数字。** 任何形式的单一数值结论都是错误输出；必须给「区间 + 前提条件 + 依据」。区间与数值一律从 MCP 实时取，不要凭记忆写。
2. **必须声明这不是成交价。** rCB 现阶段以双边长协为主，价格条款不对外披露——任何公开估值都是推导值。
3. **必须说明锚的口径限制**：主锚为 HS 28030000 **全牌号**均价，品质重心偏中低端，**仅适用标准级及以下层级，不可用于锚定高端/特种层级**。
4. **必须标注 VF 的未校准状态**（若 MCP 返回如此）。
5. **不得引用任何商业平台报价**，即使被问到也回答：本站不使用商业平台报价数据。
6. **用户拿报价问「合理吗」时，只做定性对标。** 可以说「相对于本站锚定推导的标准级参考区间偏高/偏低」，**不要判断「这个价贵不贵」**——真实成交受长协结构、账期、认证资格等本站不可见因素影响。
7. **不得把区域系数当作汇率或运费换算**。它包含合规溢价成分。

## 边界声明

本 Skill 给出的是**锚定推导的价格参考**，不是报价、不是成交价、不是估价意见。真实成交受交易结构、账期、认证资格、批量与交付条款影响，这些不在估算范围内，应提示用户。

对于高端/特种层级与尚未校准的区域，**明确回答"暂不可用"**，而不是给一个看似有理的数字。
