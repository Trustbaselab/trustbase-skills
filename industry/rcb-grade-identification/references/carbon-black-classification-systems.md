# 两套炭黑分类体系对照

> 用途：识别样品牌号时，先分清用哪一套体系。**两套体系不可互相换算。**
> 本文件不含具体数值区间——通过 MCP `get_grade_spec` 取当期条目。

---

## 一、根本区别

| | 原生炭黑 | 再生炭黑（rCB） |
|---|---|---|
| 分类标准 | **ASTM D1765** | **ASTM D8632** |
| 编码形式 | 字母 + **三位数字**（如 N550） | 字母 + **两位数字**（如 R23） |
| 编码含义 | 工艺 + 粒径档 + 结构度档 | 甲苯透光率档 + 无机物含量档 |
| 前提 | 受控合成，产品高度一致 | 反向工程产物，**原料与工艺差异大** |

**核心差异**：D1765 建立在"产品同质"的前提上（同编码可互换）；D8632 **明确不承诺同类可互换**——它解决的是"不知道怎么描述这个产品"，不是"这个产品可以替代那个产品"。

---

## 二、原生炭黑：D1765 编码

结构为 **字母 + 三位数字**：

- **首字母**：表示制造工艺（如 N 代表炉法）
- **百位数字**：与平均粒径档相关——数值越小，粒径越细、比表面积越高
- **后两位**：与结构度（DBP 吸油值相关）档相关

**使用要点**：

1. 编码是**分类标签**，具体指标区间需查标准原文
2. 同一编码在不同标准版本下区间可能微调——引用时须标版本
3. 不能只凭一个指标（如只有 BET）就判定编码

---

## 三、再生炭黑：D8632 双参数矩阵

由两个参数交叉定位：

| 参数 | 反映什么 | 对应的失效模式 |
|---|---|---|
| **甲苯透光率** | 表面有机残留水平（热解是否完全、后处理是否充分） | 分散、硫化、气味、迁移 |
| **无机物含量** | 灰分水平（原料配合剂残留） | 有效碳含量、补强效率 |

两个参数的档位组合 → 一个 **R 码**。

**为什么用参数档位而非具体数值**：因为透光率测试在不同区间的精度本身不同（高值段精度更高），所以分档采用非等距划分——这意味着**高档区间的层内离散度小于低档区间**，前者结论更可靠。

**使用要点**：

1. **R 码不是品质等级**，只说明参数落点
2. 同 R 码内部仍可能差异巨大（BET、结构度、PAH 含量都不在该矩阵内）
3. 判定"是否可替代原生"必须另做性能评估——见 `rcb-substitution-assessment`

---

## 四、检测方法体系（对应关系）

各指标都有独立的方法标准（吸碘、DBP、BET、灰分、加热减量、筛余物等）。

**引用时注意**：

- 标准会修订，方法编号的现行版本须核对
- 不同来源对同一指标的测试方法编号可能存在分歧——**在核实前不要对外标注方法编号**
- MCP `get_grade_spec` 返回的条目中已附方法与置信度，直接使用即可

---

## 五、识别时的决策顺序

```
拿到参数
  ↓ 有灰分/无机物含量？
      否 → 无法可靠区分原生与再生，先要求补测
      是 ↓
  ↓ 灰分量级接近原生典型水平？
      是 → 按 D1765 体系定位
      否 → 按 D8632 双参数定位 R 码
  ↓
与候选牌号逐项比对（compare_rcb）
  ↓
输出分类 + 不确定度 + 复检建议
```

**关键提醒**：**分类 ≠ 规格 ≠ 等价**。三步是递进的，任何一步都不能跳跃。
