## 三、可长期引用的关键事实

### 炭黑成本结构（中橡协官方文件）

```
煤焦油占炭黑生产成本 65%–80%
```

### 传导链（中橡协官方口径，2026-09-11）

```
① 焦煤：年内累计涨约 77%（主产地安检、环保督查 → 优质炼焦精煤缺口）
        ↓
② 焦化：焦炭年内只涨约 36% → 焦化亏损 → 压降开工率
        → 煤焦油（副产品）产量被动下降，部分企业减少外销转自用
        ↓
③ 煤焦油：炭黑+深加工（改质沥青、蒽油、洗油）双线抢购 + 双节备货
        → 个别拍卖成交价逼近 2022年12月历史高点
        ↓
④ 炭黑：成本被动跟涨
```

### 官方定性（可直接引用）

> **"本轮炭黑价格上涨，本质上是一次'成本驱动型、供给侧收缩型'的价格调整，而非下游需求过热或行业投机炒作所致。"**
>
> **"炭黑生产企业与下游轮胎、橡胶制品企业一样，都是本轮原材料价格波动的承压方，产业链利润正在上下游之间被成本所挤压。"**

### 其他关键数字

- 9 月部分炭黑牌号报价突破万元，逼近 12000 元/吨
- 9 月预计全行业亏损额度超 1.2 亿元
- 协会倡议：严禁哄抬价格、囤积居奇；倡导长协合作

## 四、抓取注意事项

1. **编码**：`PYTHONIOENCODING=utf-8` + `PYTHONUTF8=1`，否则中文路径在 Windows 下会乱码报错
2. **UA**：需要带浏览器 User-Agent
3. **间隔**：每篇间隔 600ms 以上，避免被限流
4. **分会页面**：正文是服务端渲染，直接 fetch 可读；无需浏览器
5. **Mysteel 页面**：导航栏很长，解析时要先定位正文关键词（如"产能利用率""开工率"）
