# 图表视觉规范与配置字段

## 一、两种图表工具

| 工具 | 用途 | 尺寸 |
| --- | --- | --- |
| `make_chart.py` | 折线图（单线/双线/多线） | 1080×900 |
| `make_data_card.py` | 数据卡片（总览/结论/清单） | 1080×1350 |

两者共用同一套配色与字体，保证系列感。

---

## 二、视觉规范（固定）

| 项 | 值 |
| --- | --- |
| 折线图尺寸 | **1080 × 900** |
| 数据卡尺寸 | **1080 × 1350** |
| 背景 | `#FAFAF8` |
| 主文字 | `#1A1C20` |
| 次要文字 | `#80848C` |
| 网格线 | `#E8EAEE` |
| 分隔线 | `#DEE0E4` |
| 红（下跌/警示） | `#CE3E34` |
| 蓝（中性/强调） | `#265CA0` |
| 橙（第三序列） | `#D6963C` |
| 灰（原料/背景线） | `#80848C` |
| 页边距 | 72px |
| 字体 | 微软雅黑 Bold / Regular |

**字号规范**：
- 折线图：标题 52 / 小标题(kicker) 28 / 轴标签 22 / X标签 20 / 末端值 30
- 数据卡：标题 84 / 小标题 30 / 主数值 56 / 主数字 74 / 正文 32 / 标签 26

## 三、`make_chart.py` 配置字段

```json
{
  "kicker": "中橡协周报 · 2026年6月–10月",     // 小标题（口径/来源）
  "title": "煤焦油和炭黑，同步冲高又同步回落",  // 主标题（手机上的钩子）
  "subtitle": "山东市场周均价，单位：元/吨",     // 副标题（可选）
  "accent": "red",                             // 顶部色条：red | blue
  "y_decimals": 0,                             // Y轴小数位；跨度<20时自动用2位
  "y_ticks": 5,                                // Y轴刻度数
  "series": [
    {
      "name": "高温煤焦油",
      "color": "grey",                         // red|blue|amber|green|ink|grey
      "values": [4116, 4200, ...],             // null 表示该点缺失
      "dots": true,                            // 是否画数据点
      "show_last": true,                       // 是否标末端数值
      "label_dx": 16                           // 末端标签水平偏移
    }
  ],
  "x_labels": ["6/1", "6/8", ...],
  "note_index": 14,                            // 标注点的索引
  "note_text": "9月14日见顶",                   // 标注文字
  "note_color": "red",
  "source": "数据来源：……",
  "author": "老赵产业观察",   // ⚠ 公众号图不要写这行，头条图才写
  "out": "炭黑周观察/图1_xxx.png"
}
```

**标注逻辑**：若给了 `note_text` 但没给 `note_index`，自动标最大值点。

## 五、已知排版坑（都已修，勿改回去）

| 坑 | 修法 |
| --- | --- |
| 标题把 "95%" 拆成两行 | `_tokenize()` 把连续 ASCII（数字/字母/%）当一个整体 |
| 句号孤立成一行 | `_wrap()` 加避头尾：`。，、；：？！）》」』】…—` 不落行首 |
| 长标签压到条形上 | 标签列自动撑宽（上限 340px） |
| 内容溢出画布 | 数据卡打印警告；理论卡自动缩放重画 |
| 比值刻度全变成整数 | 数值跨度 < 20 时用 2 位小数 |
| X 轴标签重叠 | 按标签实际宽度算步长 |
| 页脚来源压住署名 | 来源过长自动截断加省略号 |
| 双线图 Y 轴范围太紧 | 上下各留 16% padding |

## 六、配色语义（保持一致）

| 语义 | 颜色 |
| --- | --- |
| 下跌 / 警示 / 成本压力 | 红 `#CE3E34` |
| 中性 / 强调 / 产品线 | 蓝 `#265CA0` |
| 第三序列 | 橙 `#D6963C` |
| 原料 / 背景参照线 | 灰 `#80848C` |

**原则**：**原料用灰（背景），产品用彩（主体）**。这样读者一眼能分清哪条是驱动因素、哪条是被驱动方。
