# 国产大模型对比框架

## 一、先说一个前提：不做"谁最强"

**原因**：
1. 评测榜单口径不同，没有统一答案
2. 同一模型在不同任务上表现差异巨大
3. "最强"对读者没用 —— 读者要的是"我这个场景该用谁"

**所以本栏目做的是：什么场景用谁 + 性价比拐点在哪。**

---

## 二、三维对比框架

### 维度一：能力

| 榜单 | 测什么 | 局限 |
| --- | --- | --- |
| **C-Eval** | 中文知识（选择题为主） | 偏知识，不测实际任务 |
| **SuperCLUE** | 中文综合能力 | 更新频率低 |
| **LMArena** | 人类偏好对战 | 偏"讨喜"，不一定是"好用" |
| **智能体榜单** | 多步任务、工具调用 | 最接近实际工作，但覆盖面窄 |
| **未来图灵 AI 明星企业榜** | 企业维度 | 不是模型能力榜 |

**用法**：至少看两个榜单，且**必须说明每个榜单测的是什么**。

⚠ **不能把不同榜单的分数放一起比** —— 那是低级错误。

### 维度二：价格

**必查项**：
- 输入价格（每百万 token）
- 输出价格（每百万 token）
- 是否有缓存价、批处理价
- 免费额度

**关键指标**：**性价比拐点**

> 当能力接近时，价格差 10 倍，用户的决策就变成了"够用就行，选便宜的"。

**这正是国产模型的真实优势所在** —— 不是"追上了"，是"同样的能力，便宜多少"。

### 维度三：算力

**这是国产模型最真实的约束。**

| 看什么 | 为什么重要 |
| --- | --- |
| 训练用了多少卡 | 决定模型上限 |
| 推理成本 | 决定能否大规模商用 |
| **芯片来源** | **决定长期可持续性** |
| 是否有自研芯片 | 决定能否摆脱依赖 |

**角度**：
> 国产模型的真正短板，不是"差一点"，是"算力受制于人的那一部分"。
> 而突破点不一定在单卡性能，可能在"体系"——用更多卡、更好的调度，做出接近的效果。

## 三、写作模板

### 模板 A：单点对比（如新模型发布）

```
[模型] 刚发了新版。

先说它考了多少分：[分数]，在 [榜单] 上排 [位置]。
但分数不是重点。

真正的看点是三件事：
① 能力：在 [具体任务] 上，和 [对标模型] 差多少
② 价格：每百万 token [X] 元，比 [对标] 便宜/贵 [Y]%
③ 算力：训练用了 [Z]，这个数字决定了它能不能持续迭代

我的判断：[一句话]

对普通用户意味着什么：[实用结论]
```

### 模板 B：横向对比（多模型）

**做成表格，别做成段落。**

| 模型 | 能力（某榜单） | 输入价 | 输出价 | 适用场景 |
| --- | --- | --- | --- | --- |
| A | 85 | 1 元 | 3 元 | 通用对话 |
| B | 83 | 0.5 元 | 1.5 元 | 高并发 |
| C | 90 | 8 元 | 24 元 | 复杂推理 |

**结论必须是"场景建议"，不是"排名"。**

### 模板 C：算力视角

```
国产模型的竞争，表面看是模型，底层看是算力。

这周有个信号：[事件]

拆开看：
- 单卡性能：和海外差距 [X]
- 但可以用 [方法] 补：更多的卡 + 更好的调度
- 这条路能不能走通，关键看 [指标]

我的判断：[一句话]
```

## 四、必须避开的坑

| 坑 | 表现 | 解法 |
| --- | --- | --- |
| **榜单混用** | 把 C-Eval 分数和 LMArena 排名放一起比 | 每个榜单单独说明 |
| **只比分数不比价格** | "我们超过 GPT" | 补一句"但贵了 3 倍" |
| **忽略算力约束** | "我们能追平" | 要问"用什么算力追平的" |
| **把厂商宣传当数据** | 直接抄发布会 PPT | 找第三方评测 |
| **绝对化** | "最强""吊打" | 换成"在某场景下更好" |

## 五、选题池

| 选题 | 角度 |
| --- | --- |
| 某新模型发布 | 能力/价格/算力三维拆解 |
| 模型价格战 | 谁在降、降了多少、为什么 |
| 开源 vs 闭源 | 国产开源模型的真实水平 |
| 智能体能力 | 从"能聊"到"能干活"的差距 |
| 中文能力 | 国产模型的主场优势有多大 |
| 算力突破 | 单卡不行，体系能不能补 |
| API 价格 | 每百万 token 到底多少钱，换算成"一次对话多少钱" |

---

## 六、给普通读者的一句话

**模型对比对普通人的意义，不是"谁第一"，是"同样的活儿，现在多少钱能干完"。**

这个角度写，读者才看得懂、才愿意看。
