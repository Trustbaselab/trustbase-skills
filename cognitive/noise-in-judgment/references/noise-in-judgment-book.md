## 一句话论点

凡有判断之处就有噪声，且比你想的多：本应相同的判断之间存在巨大而隐蔽的随机变异；噪声与偏差对误差的贡献可互换（MSE = 偏差² + 噪声²），但噪声可以在不知道真相时被测量、被流程性地预防（决策卫生）。

## 核心论证链

```
判断错误 = 偏差（系统性） + 噪声（随机离散）
→ 误差方程：MSE = 偏差² + 噪声²（第 5 章）
→ 噪声可测（无需真相）：噪声审计量化分歧（第 2 章、附录 A）
→ 分解：系统噪声² = 水平噪声² + 模式噪声²；模式噪声 = 稳定模式噪声 + 场合噪声（第 6–7 章）
→ 根源：启发式差异、强度匹配、模糊量表、过早直觉、群体级联/极化（第 13–17 章）
→ 处方：决策卫生 = 独立判断→聚合、结构化分解（MAP）、排序优于打分、统一量表、信息排序、规则化（第 19–25 章）
→ 边界：最优噪声——尊严、价值观演化、创造力、威慑不确定性（第 26–28 章）
```

## 概念词典（要点版）

| 概念 | 精确定义（书中原意） | 常见误解 |
|---|---|---|
| 判断 judgment | 以人脑为工具、以准确为目标的测量；介于纯计算与纯品味之间 | 当意见表达；混淆预测性/评估性判断 |
| 偏差 bias | 系统性误差：一组判断平均偏离真值 | 只指歧视；以为去偏=消除全部错误 |
| 噪声 noise | 本应相同的判断之间的变异；系统噪声=不受欢迎的变异 | 与偏差混用；当小问题 |
| 误差方程 | 总误差(MSE) = 偏差² + 噪声² | 以为偏差未测就无需降噪 |
| 水平噪声 level noise | 判断者平均水平的差异 | 以为人差=全部噪声 |
| 模式噪声 pattern noise | 判断者×案例的稳定交互差异；通常最大成分 | 忽略；它是「判断人格」 |
| 场合噪声 occasion noise | 同一人不同时刻的差异（情绪/疲劳/天气/顺序） | 以为专家恒定；证据偏弱需对冲 |
| 噪声审计 noise audit | 独立判断同一批案例、量化分歧的测量程序 | 当考核工具；只做一次 |
| 一致性错觉 illusion of agreement | 流程掩盖分歧、人人以为一致 | — |
| 效度错觉 illusion of validity | 把解读证据的连贯感当成预测准确度 | 与自信混淆 |
| 决策卫生 decision hygiene | 不针对具体偏差、流程性预防未知错误的措施（洗手类比） | 当多检查；以为需先确诊偏差 |
| 中介评估法 MAP | 定维度→独立评估→评-议-评→最后整体判断 | 当打分表；以为排除直觉 |
| 统计群体 > 互动群体 | 独立判断聚合优于讨论共识（级联、极化放大噪声） | 以为头脑风暴降噪 |
| 内部群体/辩证自助 | 同一人两次独立判断平均更准；换角度生成第二判断 | 「再想一次」≠独立 |
| 匹配 matching | 印象强度映射到量表数值；绝对匹配粗糙、相对精确 | 忽略量表即噪声源 |
| 任意连贯性 | 任意锚点上的内部一致性，换锚点整体漂移 | 评分高=判断好 |
| 外部视角 outside view | 个案放入同类分布看基准率 | 与「经验」混淆 |
| 客观无知 | 预测准确性的理论上限（未来不确定+信息局限） | 用「模型也错」否定模型优势 |
| 机械预测/算法 | 无噪声的规则/模型；元分析普遍不输临床直觉 | 算法必复杂；算法无偏差 |
| 合理规则 reasoned rule | 6–8 变量标准化求均值→分数段定行动（五步） | 必须建复杂模型 |
| 断腿例外 broken-leg | 模型不知道的决定性信息→可推翻，但须记账审计 | 直觉覆盖的通行证 |
| 规则 vs 标准 | 规则消噪声但僵化；标准灵活但产噪声 | 一律规则化 |
| 最优噪声 | 部分噪声有价值（尊严、价值观演化、威慑） | 零噪声理想 |

## 证据锚（引用时保留语境，勿夸大）

1. **保险核保审计**：定价中位差 55%、理赔 43%，高管预期约 10%；年损失估「数亿美元」。非同行评议案例（作者自述），数字经 strategy+business 书评转述。
2. **828 名高管预期**：对专家分歧预期中位数 10%；实测常见 4–5 倍。
3. **HBR 2016 噪声测量**：两家金融机构 10 项判断——A 机构 6 项 34%–62%（均值 48%）、B 机构 4 项 46%–70%（均值 60%）；经验年限不降噪。
4. **量刑**：海洛因贩子 1–10 年、银行劫匪 5–18 年；1984 强制指南缩小差异，2005 Booker 改建议性后差异翻倍（底层研究待核实）。书中 208 法官×16 案、平均 7 年、极端 30 天–15 年（二手一致，精确出处待核实）。
5. **庇护顺序效应**：连续批准后下一个批准率下降（Chen, Moskowitz & Shue, NBER 2014/AEA 2016）。
6. **「饥饿法官」**：假释批准率随用餐休息波动（Danziger et al., PNAS 2011）；有 PNAS 学术往来争议（Weinshall-Margel & Shapard 批评 + 作者回应）——引用标「证据锚」。
7. **天气与录取**：阴天重学术属性（Simonsohn 2007, bdm.545）；小样本自然实验。
8. **指纹鉴定**：同一人对同一指纹数周后改结论（书转述 Dror 系列；精确比例待核实）。
9. **医学**：钼靶假阴性 0→>50%；病理学家自评重测相关 r=0.63（doi 10.1037/h0037164；HBR 记 0.61）；Apgar/Centor 为指南降噪范例。
10. **绩效与招聘**：评分变异 70–80% 与真实绩效无关（Scullen et al. 2000, JAP 85:956 等；「62%」口径待核实）；两位面试官评分相似概率 62–65%。
11. **软件估时**：同一项目估时中位差 71%（书引，doi 10.1016/j.jss.2007.03.001）。
12. **机械预测**：Meehl (1954) 开创；Grove et al. (2000, Psychol. Assess. 12:19–30) 元分析——机械预测约半数胜出、其余打平；Dawes (1979) 均等权重模型的稳健之美。

## 可操作原则（书中证据推出）

1. 先审计再开药：同工同判的流程都应测分歧，不用印象替代测量。
2. 审计前领导先写预期分歧并承诺行动。
3. 测离散不测平均；报分歧指标与水平/模式分解。
4. 独立判断再聚合；禁止先讨论。
5. 结构化分解（MAP），最后才整体直觉。
6. 排序优于打分；打分必须给锚点。
7. 统一量表与参照框架（行为锚定、参照框架培训）。
8. 信息排序：先证据后背景（线性顺序披露）。
9. 外部视角：先基准率再个案。
10. 高频可验证判断规则化（合理规则五步）。
11. 断腿例外记账审计，不当通行证。
12. 选判断者看积极开放性思维与校准。
13. 单一决策用决策观察者 + pre-mortem + 反事实思考。
14. 定期复审计（制度会漂移）。

## 批评与边界（引用时的红线）

1. 噪声=方差是经典测量理论内容；本书贡献在「组织化审计与预防」，不在新数学（Chance 2024 书评存在，正文未读，此表述按通行统计共识转写）。
2. 算法无噪声但有偏差风险：训练数据偏差、代理变量、公平性争议（COMPAS 等）；AI Magazine 评论指出专家分歧使 ML 的「真值」构造成问题。
3. 噪声审计可行性有限：需同质案例、可互换判断者、可复跑；保密领域与单一决策难审计；审计可被博弈。
4. 场合噪声证据偏弱：小样本观察性、效应量小、有复制争议（Danziger 案）。
5. 治疗可能比疾病更糟：粗糙规则僵化（三振出局、crack 量刑差异）；应换更聪明的规则。
6. 尊严与个别化对待是合法价值（第 27 章）：最优噪声不是零噪声。
7. 评估性判断的「真值」是社会建构：统一量表可能固化某群体的价值观；批评者认为书低估此张力。
8. 元分析结论是「机械预测不差于临床」，且多无独立样本外检验；个案上须留断腿例外。
9. 噪声不是免责条款：机制描述与结构责任要分开说。

## 对 agent 工作的映射（9 条）

1. 单次 LLM 输出是「内部分布的一次抽样」——关键判断默认标「单次抽样」，重要场景重跑聚合。
2. 多轮不一致 = 场合噪声；跨模型倾向差 = 水平噪声；对某类用例不稳定 = 模式噪声——分开诊断再开药。
3. 独立判断再聚合：子代理独立作答后投票/取中位，不串行参考前者答案。
4. MAP 的 agent 版：先 rubric 逐维度评分，最后综合；禁止先给总分。
5. 排序替代打分：候选排序优于 1–10 分；打分给行为锚。
6. 确定性规则优先：能写代码/公式/查表的判断不交给 LLM 直觉；例外记账。
7. prompt 信息排序：事实在前、结论与锚点在后；疑顺序敏感就轮换测。
8. 输出报告分布与口径（n、范围、聚合方式、真值可得性），不报虚假单点。
9. 一致性检查原始输出存档，指标可复算。
