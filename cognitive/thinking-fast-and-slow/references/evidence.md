## 真实应用案例

### 案例 A · 复核流程捕获「×1.3」的无源直觉数字（2026-10-18）

| 项 | 内容 |
|---|---|
| **问题** | 本 skill 初稿的 agent 协议写「估时一律 ×1.3」——一个读起来流畅、但**没有任何出处**的参数；同一文件的余闲规则又写「约 20% 缓冲」，两个数自相矛盾（30% 缓冲 vs 1.3 倍估时，方向相反）。若直接交付，agent 会拿着一个无依据的数字执行排期 |
| **书里哪个概念** | **认知放松（cognitive ease）/流畅≠正确**：无摩擦写出的数字最常见的来源是「感觉对了」，而不是证据；**A5 参考类与基准率**：任何估计参数必须能追到基线或来源；**A2 检索留痕**：结论要能回答「依据是什么」 |
| **具体做法** | 审查清单增加「数字必须可追到笔记/来源」条目；独立审查员以研究笔记为基准逐条对照，命中「×1.3 无出处 + 与笔记 ×1.5–2 冲突 + 与 20% 缓冲矛盾」；lead 改为 **×1.5–2**，并在 SKILL.md 新增「操作参数口径」表，逐项标注「书内证据（含待核实状态）/ skill 自定」 |
| **量化结果（前 → 后）** | 前：**1 条无源参数**（×1.3），发现**1 处与笔记冲突 + 1 处内部矛盾**；后：无源参数 **0 条**，冲突与矛盾清零；4 项操作参数（估时系数/日程缓冲/深块时长/每日块数）全部带来源标注；该错误在交付前被拦截，未流入使用 |

> 诚实边界：这是「复核流程捕获一次错误」的案例（样本 = 1 次审查），不能表述为「本 skill 提升了产出质量」的对照实验；其余规则仍待验证（见下表）。
