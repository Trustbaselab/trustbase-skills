# METHOD：`thinking-fast-and-slow` 这本书是怎么被做成 skill 的

> 记录「《思考，快与慢》→ agent 复核协议」的转化过程，供后续同类 skill 参考。

---

## 一、核心判断：这本书为什么适合

**作者在跟谁争论**：跟「人知道得比实际上多」的信念争——尤其是跟「专家直觉可靠」「理性人是常态」的主流假设争。卡尼曼的立场：偏差是**系统性的、有触发条件的、可预测的**，因此可以被**外部流程**对冲；但「知道」不等于「免疫」（他自己 Ch.4 就是证据）。

**为什么适合做成 AI skill**：LLM/agent 的默认输出路径（next-token 联想式生成）在功能上≈系统 1——追求连贯、流畅、自信，但不等于正确。书的全部概念（锚定/可得性/代表性/框架/损失厌恶/过度自信/计划谬误/WYSIATI）都有明确的**触发条件**，可以翻译成 agent 可执行的 if-then 复核规则。打分：立场 5/5 · 可翻译 5/5 · 同源 4/5 · 可验证 3/5（待验证）。

**红线预埋**：Ch.4 启动研究、自我耗竭、热手错觉已被复制危机推翻——skill 从一开始就把「哪些概念可用、哪些不可用」写进边界表，防止 skill 变成书里错误结论的放大器。

## 三、翻译成的 10 条核心准则（if-then，已全部入 SKILL.md 处方库）

1. IF 输入带具体数字/草稿 THEN 先写独立基准再处理给定值（**A1** 反锚定）
2. IF 结论依赖最近/最显眼的材料 THEN 先补「查了什么/没查什么」两栏再定论（**A2** 反可得性）
3. IF 只有个案无分布 THEN 先报基准率，缺失就明说「基准率未知，置信度下调」（**A3** 反代表性）
4. IF 建议涉及损失/收益表述 THEN 双框架各写一遍，不一致点列为第一风险（**A4** 反框架/损失厌恶）
5. IF 要估时/估成本 THEN 取同类历史分布中位数起步 ×1.5–2，并写最乐观假设（**A5** 反计划谬误）
6. IF 归因是「因为 X 所以 Y」的单因果叙事 THEN 自问「相反结果是否同样讲得通」（**A6** 反叙事谬误）
7. IF 单一极端结果出现 THEN 先对照历史波动，再谈归因（**A7** 回归均值检查）
8. IF 结论影响关键决策 THEN 附置信度/不确定项/验证步骤/替代解释四要素，凑不齐就声明未达标（**A8** 校准输出）
9. IF 影响不可逆决策 THEN 红队复核 + 预验尸 + 外部视角面板（**B1/B2/B3**）
10. IF 输出流畅笃定但无据 THEN 强制三层改写：事实/推断/猜测（**C1**）

## 五、失败/风险记录

1. **本书自身的最大教训**：作者写《小数定律》40 年后栽进小样本（Ch.4）。skill 因此禁止任何「警觉/自律」类处方，只接受外部流程。
2. **不可用概念清单**（复制危机）：启动/priming、自我耗竭、热手错觉；损失厌恶保留「≈2 倍、有争议」对冲；饥饿法官只当轶事。
3. **类比边界**：AI 的系统 1/系统 2 是功能类比，不是容量或脑科学主张——已在 SKILL.md 开头与边界表双重声明。
4. **审查修复记录**（2026-10-18，skill-review-a.md）：8 项轻微问题（evidence 勾选矛盾、处方编号隐式、问 1 缺「无法观察」档、A8 与禁编造冲突、清单缺适用阶段、引文缺页码标注、词典 25 条超限、description 丢触发词）已全部修复；另补 factfulness/noise 互引路由与「结构审查模式」最小模板。
