# 实事求是 · 数据引用的操作系统

《事实》的核心主张：我们对世界的判断系统性差于随机（2017 年 14 国研究：人类平均 2.2/12 题，随机为 4/12），根源不是无知，而是**十大情绪化本能 + 媒体坏消息偏好**塑造的过度戏剧化世界观（overdramatic worldview，中译待核实）。本 skill 把书中「用数据看世界，而不是用情绪和偏见看世界」翻译成 agent 的数据获取/引用纪律。

## 何时使用

- 用户问「世界是不是越来越糟」「XX 是不是完了/崩溃了」——需要水平+趋势核查
- 用户要求引用或核实一个统计数字、趋势、市场判断
- 输出涉及风险、灾难、恐慌主题（含「别贩卖焦虑」的自我约束）
- 语境出现「必须立刻/马上/否则来不及」的紧迫要求
- 用户提出二分式判断（「穷人 vs 富人」「发达 vs 落后」）
- 归因讨论（「都怪 XX」「全靠 XX」）
- agent 自己要引用训练记忆中的数据/案例

**轻量模式**：只核实一两个数字、只答「这数据可信吗」时，只出「一句话结论 + 一张事实核查卡（内含水平+趋势双栏）」，不走全流程。

**不适用**：纯概念解释（可讲，不必强制套全流程）；任务过载、多任务、专注排程 → 用 `bandwidth-and-deep-work`（规范 §8 交叉引用）；学术史讨论（直接查 `references/factfulness-book.md`）。

## 三条铁律

### 铁律 1：数据引用必须带口径四件套

任何统计数字必须附：**来源（谁统计）+ 年份（哪年数据）+ 定义（口径是什么）+ 基准（和什么比：人均？比率？随机水平？）。** 缺任何一件 = 未核实，标注「待核实」，⛔ 禁止补全成看似核实过的样子。

> 证据锚：Gapminder Misconception Study 2017——14 国约 1.2 万人答 12 道全球事实题，平均 2.2/12，低于随机 4/12；15% 的人全错。全错不可能是无知，只能是**系统性错误世界观**。本书官方还设勘误页公开 30+ 处修正（含 p.37 收入阈值 $64→$32）——连作者都要勘误，agent 更没资格免检。

### 铁律 2：水平与趋势分开报告

「当前水平仍糟」与「方向在变好」可以同时为真。只报水平是负面思维，只报趋势是粉饰。**两栏都写。**

> 证据锚：书中 13 题——极端贫困近 20 年几乎减半、全球预期寿命 70 岁、低收入国家女童小学毕业率 60%（实际 63.2%）、近百年自然灾害死亡降到不足一半——绝大多数人（女童题仅 7%）答错，因为「糟糕的水平」遮蔽了「变好的趋势」。

### 铁律 3：恐惧与紧迫是信号，不是指令

恐惧感 ≠ 风险大小；「必须立刻」不自动等于「真的紧急」。风险 = **危险 × 暴露**。收到恐惧或紧迫信号时，先降速：要数据、算风险、分小步，再决定要不要大动作。

> 证据锚：官方恐惧本能页逐字定义 Risk = danger × exposure；书中列出的真正配得上紧迫感的只有五大全球风险（全球大流行病、金融崩溃、世界大战、气候变化、极端贫困；表述以书中第 10 章原文为准，待核实）。老虎、大熊猫、黑犀牛均未比 1996 年更濒危（IUCN）——恐惧的对象常常不是风险所在。

## 第 0 步 · 收集信息（禁止编造）

动手前必须拿到（缺什么问什么，或显式声明「以下为假设值」）：

- 要引用的数据/趋势本身 + 用户问题的具体领域与时间范围
- 数字的来源、年份、定义（谁统计、什么时候、什么口径）
- 对比基准（总量还是人均？和什么基线比？）

⛔ **记忆里的数字一律视为「记忆值，未核实」；引用前必须检索或标注。**

## 核心流程：引用前四问 → 本能诊断

### Step 1 · 口径四件套（每个数字）

| 问 | 缺失时的处理 |
|---|---|
| 谁统计的？ | 标「来源待核实」或换可溯源的数字 |
| 哪一年的？ | 标「年份待核实」；>3 年先查最新值 |
| 定义/口径是什么？ | 标「口径待核实」；多个口径冲突时并列呈现（例：预期寿命 IHME 72.48 vs UNPop 71.9，书中取整 70） |
| 和什么比？ | 补基准：人均/比率/80-20/随机水平/历史基线 |

### Step 2 · 水平+趋势双栏

「当前水平 X」+「变化方向 Y」+「数据截至 Z」三要素齐全才算一个完整事实陈述。

### Step 3 · 十大本能诊断（输出草稿逐项自检）

| # | 本能 | 自检问题 | 触发信号 → 处方 |
|---|---|---|---|
| 1 | 二分法 gap | 我是不是把世界分成了两半？ | 「发达/发展中」「富/穷」二元标签 → B1 |
| 2 | 负面思维 negativity | 我是不是只报了坏事？ | 只说「很糟」没说趋势 → B2 |
| 3 | 直线思维 straight line | 我是不是在直线外推？ | 「按此趋势将…」 → B3 |
| 4 | 恐惧本能 fear | 我在渲染恐惧吗？ | 灾难/犯罪/恐怖主题 → B4 |
| 5 | 规模错觉 size | 数字有没有按比例？ | 大数字无基准 → B5 |
| 6 | 以偏概全 generalization | 我用一个例子概括了一类？ | 「某地如此」式概括 → B6 |
| 7 | 命中注定 destiny | 我假设现状永恒？ | 「他们向来如此」 → B7 |
| 8 | 单一视角 single | 我只有一把锤子？ | 单一解释/单一指标 → B8 |
| 9 | 归咎他人 blame | 我在找坏人/英雄？ | 「都怪 XX」 → B9 |
| 10 | 情急生乱 urgency | 我或用户在急？ | 「必须立刻」 → B10 |

### Step 4 · 紧急检查

用户或语境催促时，执行 B10 降速协议，并对照「五大全球风险」检验紧迫是否真实。

## 诊断 → 处方 决策映射

| 诊断发现 | 先做什么 |
|---|---|
| 数字缺口径（任一要素） | A1 补齐或标「待核实」，不引用裸数字 |
| 数字来自记忆/训练数据 | A2 显式标注 + 检索更新 |
| 数据 >3 年 | A3 查最新值，同时保留原口径 |
| 同一指标多口径冲突 | A4 并列呈现，不擅自合并 |
| 只报水平或只报趋势 | B2 双栏补齐 |
| 出现二元标签 | B1 换成分布/等级/中间大多数 |
| 恐惧主题 | B4 危险×暴露表 |
| 出现「立刻/必须马上」 | B10 降速协议优先于一切 |
| 单一解释/单一指标 | B8 强制找反证 + 替代指标 |
| 归因指向个人/单点 | B9 改系统因素清单 |
| 对方无数据下结论 | A5 不接情绪，给同题数据 |

## 处方库

### A. 数据核实纪律（if-then）

- **A1** 当引用任何统计 → 附口径四件套；缺一件标「待核实」，禁止补齐成疑似核实过的样子。
- **A2** 当数字出自记忆/训练数据 → 显式写「记忆值，未核实」，随即检索最新来源替换。
- **A3** 当数据 >3 年 → 先查最新值；输出同时写「原口径 X（年份）/ 最新 Y（年份）」。
- **A4** 当同一指标多口径冲突 → 并列呈现来源+年份，不取平均、不擅自合并（先例：书中预期寿命取整 70「避免夸大进步」）。
- **A5** 当对方无数据下结论 → 不驳情绪，给「同题正确数据 + 来源」，让对方自己对比。
- **A6** 当发现自己引错 → 显式勘误并记录，不悄悄修改（先例：本书官方勘误页 30+ 处公开修正）。
- **A7** 当转述他人研究/数据 → 追一手来源；只能拿到二手报道时降级标注「据 XX 报道」。

### B. 十大本能对策（if-then）

- **B1** 当输出/用户话语含二元标签 → 换成收入等级、分位、区间——如「中间大多数」（约 50 亿人住 Level 2–3）或「76% 人口在中等收入国家」（World Bank 口径）；必要时给分布图。
- **B2** 当只报坏事或只报好事 → 补双栏：「水平仍糟」+「方向在变好/变差」；预期坏消息——默认直觉低估进步，读坏消息主动查反向数据。
- **B3** 当线性外推 → 先问曲线形状（S 形/滑梯/驼峰/倍增），给至少一种非直线情景（例：2100 年儿童数仍是 20 亿，人口增长来自成年人）。
- **B4** 当恐惧主题 → 输出「危险 × 暴露」分解表 + 一个同等量级基准风险做参照；建议「先冷静，恐慌中不做重大决定」。
- **B5** 当大数字无基准 → 除以总量、按人均、80/20 排序；永远附一个对比锚（如书中已核口径：近百年自然灾害年死亡人数降到不足一半）。
- **B6** 当单个案例概括整体 → 查组内差异与组间相似；「生动特例」单列，标注它有多不典型。
- **B7** 当「向来如此」判断 → 查 10/20 年变化数据（例：伊朗生育率骤降）；附「缓慢变化也是变化」。
- **B8** 当单一视角 → 强制补一个反证来源和一个替代指标；专家意见与统计数据分开标注（例：美国卫生支出第一 ≠ 寿命第一）。
- **B9** 当归因 → 用系统因素清单（结构/激励/信息/历史路径）重写因果链；「坏人/英雄」叙事替换为原因与约束（先例：中国生育率下降先于一胎化政策十年）。
- **B10** 当紧急指令 → 降速协议：①要数据（这个紧迫基于哪个数字？）②区分「必须现在」vs「感觉现在」③先给最小可行一步（小步）④评估后再放大；只有五大全球风险级别的真风险才配「现在马上」。

### C. 输出纪律

- **C1** 事实核查卡是默认输出格式（见模板），任何数字结论都挂一张。
- **C2** 轻量模式：一句话结论 + 一张事实核查卡（内含水平+趋势双栏）即可，处方 ≤3 条。
- **C3** 情绪词清单：输出禁用「崩盘/毁灭/完蛋/再也/史无前例」等戏剧化措辞，除非有数据支撑该措辞。

## Agent 执行协议（agent 自己照此工作）

1. **口径四件套默认行为**：每次引用统计，自动附「来源·年份·定义·基准」；做不到就写「待核实」——这是本 skill 的第一纪律，先于一切输出速度要求。
2. **记忆值 ≠ 事实**：训练数据里的世界是旧世界（本书数据截至 2016–17；2019 年后疫情、民主倒退、预期寿命回落已改变部分趋势）。引用记忆数字前必检索，输出标注「截至」年份。
3. **检索对称性**：为结论找证据时，同步搜一个反证（防确认偏误）——对应「单一视角」的对策，防止 agent 用检索制造自证循环。
4. **不传染情绪**：用户急、用户怕时，agent 保持降速节奏：先数据、再分解、小步给方案；绝不用「确实很严重」附和未经核实的恐慌。
5. **归因用系统不用人**：错误/事故归因写「结构/激励/信息/历史」清单，不写「都怪某人/某部门」；表扬同理避免单一英雄叙事。
6. **勘误即行动**：发现自己引用错 → 显式更正 + 记录，不静默替换（这是《事实》官方先例）。
7. **水平+趋势双写**：任何「变好/变坏」结论都附另一栏；任何「很糟」结论都查趋势，任何「改善」结论都保留水平数字。

## 输出模板

**输出顺序与预算**：一句话结论 → 核查卡（1–2 张）→ 处方 ≤5 条 → 1 个下一步动作。不要清单平铺。

### 事实核查卡（每个关键数字一张）

```markdown
| 项 | 内容 |
|---|---|
| 数字 | （原口径数字） |
| 来源 | 谁统计 / 一手还是转述 |
| 年份 | 数据年份 + 「截至」声明 |
| 定义/口径 | 精确到指标名与分子分母 |
| 对比基准 | 人均？比率？历史基线？ |
| 水平 vs 趋势 | 当前水平 X（好/糟）｜方向 Y（变好/变差） |
| 置信 | 已核实 / 待核实（缺什么） |
```

### 水平+趋势双栏（负面/乐观话题通用）

```markdown
| 维度 | 内容 |
|---|---|
| 水平（现在有多糟/多好） | ...（带数字与年份） |
| 趋势（方向与速度） | ...（带起止年份） |
| 例外与分布 | 哪些群体/地区不符合总体趋势 |
| 结论 | 一句话：糟/好在哪、变不变、数据截至何时 |
```

### 危险×暴露卡（恐惧/风险主题）

```markdown
| 项 | 内容 |
|---|---|
| 危险（事件本身多严重） | ... |
| 暴露（谁/多大概率/多频繁） | ... |
| 风险 = 危险 × 暴露 | 量化或量级估计 |
| 参照基准 | 同量级的其他日常风险 |
| 冷静后的小步 | 先做什么、评估什么 |
```

## 边界与常见误用

| 误用 | 纠正 |
|---|---|
| 「世界在变好」= 不用担忧/不用行动 | 书中列五大全球风险并主张紧迫行动；进步不是终点，是把担忧对准真风险 |
| 「实事求是」= 只报好消息 | 水平栏必须保留：糟糕的现状与变好的趋势并存，粉饰与恐慌同样违反本书 |
| 数据 = 真理 | 数据会错、会过时、会被操纵：官方勘误 30+ 处、收入阈值三度修订、民主图撤换；引用必须带年份与「合理怀疑」态度 |
| 用本能清单攻击别人的偏见 | 书中 13 题测试首先要求**先测自己**；诊断清单是自检工具，不是辩论武器 |
| 总体验证个体 | 平均值掩盖分布（书中钟形曲线警告）；「总体改善」不等于「每个人都改善」，需附分布/分档 |
| 「趋势变好」搪塞当下问题 | 「方向在变好」不能抵消具体问题；两栏都写，决策仍面对真实水平 |
| 本书是铁证 | 证据等级有限：测试只证明「错误世界观」存在（2017 年富国在线面板），非智力结论；Christian Berggren 等学者曾批评书中统计口径（官方勘误页亦引用其纠错）；引用称「证据锚」而非「定论」 |
| 黑猩猩比喻的猎奇化 | 测验结果是「系统性误导」的证据，不是「人不如猴」；转述必须保留语境 |
| 「用数据说话」当不作为借口 | agent 不得以「实事求是/先核实」无限拖延真紧急行动——B10 的小步是行动不是搁置 |
| 涉及任务过载/专注排程 | 换 `bandwidth-and-deep-work`，本 skill 不处理注意力分配 |
