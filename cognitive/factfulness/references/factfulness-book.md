## 一句话论点

大多数人对全球进展的判断系统性差于随机（2017 年 14 国：平均 2.2/12 题，随机 4/12，15% 全错），根源不是无知而是**十大戏剧化本能 + 媒体坏消息偏好**塑造的过度戏剧化世界观；用「数据口径纪律 + 本能识别 + 水平/趋势分开」重建实事求是（factfulness）的习惯——世界仍有很多坏东西，但远好于我们的印象，纠正认知是为了把担忧对准真正重要的五大全球风险。

## 核心论证链（紧凑）

```
13 题黑猩猩测试：系统性答错（非随机无知）
→ 方向一致：低估进步、高估灾难（贫困减半/寿命 70/女童入学 60% 大多答错）
→ 机制：十大本能 × 媒体坏消息偏好 × 过时教育 = 过度戏剧化世界观
→ 后果：错误世界观 → 错决策（错失市场/资源错配/恐慌决策）
→ 对策：每个本能一条拇指规则 + 口径纪律 + 谦卑与好奇
→ 边界：实事求是 ≠ 乐观；五大全球风险（大流行病/金融崩溃/世界大战/气候变化/极端贫困）才配紧迫
```

## 概念词典（要点版）

| 概念 | 精确定义（书中原意） | 常见误解 |
|---|---|---|
| 实事求是 factfulness | 「只对有强证据支持的观点持有意见的减压习惯」（官网逐字） | =乐观/正能量；实为证据约束意见的纪律 |
| 过度戏剧化世界观 overdramatic worldview | 系统性高估坏事、低估进步的认知状态（本能+媒体+过时知识） | 全怪媒体；本能是内因 |
| 本能 instinct | 进化中帮助生存的注意力捷径，今天系统性误导（与 Kahneman「偏差」有别，原文待核实） | 与认知偏差混同 |
| 二分法本能 gap | 把世界分成两极 | 中文「一分为二」辩证法语义混淆 |
| 负面思维本能 negativity | 注意坏消息、忽略渐进改善；解药=预期坏消息+区分水平与趋势 | 「预期坏消息」=悲观 |
| 直线思维本能 straight line | 线性外推；现实多为 S 形/滑梯/驼峰/倍增 | 一切趋势当直线 |
| 恐惧本能 fear | 对伤害/受困/污染的自动化恐惧放大感知风险；解药：风险=危险×暴露（官网逐字） | 恐惧感=风险 |
| 规模错觉 size | 孤立数字/局部画面失去比例；解药：比较与除法、人均、80/20 | 只防「大数字吓人」 |
| 以偏概全 generalization | 个例外推、组内同质化；解药：组内差异+组间相似+质疑分类 | 只针对地域偏见 |
| 命中注定 destiny | 把文化/国家当不变命运；解药：缓慢变化也是变化、更新知识 | 把尊重文化当文化不变 |
| 单一视角 single | 锤子综合征、单一指标；解药：工具箱+检验想法+专家≠全知 | 反专家主义 |
| 归咎他人 blame | 找坏人/英雄；解药：找原因与系统 | 找系统=为个人开脱 |
| 情急生乱 urgency | 紧迫感关闭理性；解药：小步前进、要数据、警惕预测 | 反对一切紧急行动 |
| 收入四等级 | 人均日收入四级（书 2018：$1/$4/$16/$64，勘误 $32；官网现行 <$2/$2–8/$8–32/>$32）；人口约 1B/3B/2B/1B | 与「四分位」混淆；阈值会修订 |
| 中间大多数 | 约 50 亿人住 Level 2–3；中等收入国家占 76% 人口 | 继续富/穷二分 |
| 水平 vs 趋势 | 「水平糟」与「方向变好」可同时为真 | 报喜不报忧 / 报忧不报喜 |
| 好消息不是新闻 | 渐进改善无报道价值；媒体坏消息偏好放大世界观 | 反媒体；实为反向补偿策略 |
| 五大全球风险 | 大流行病/金融崩溃/世界大战/气候变化/极端贫困（表述待核实） | 拿本书当「什么都不用担心」 |
| 谦卑与好奇 | 承认本能与无知、坦然说「不知道」；主动找与世界观不符的事实 | 「不知道」=无能 |
| 系统思维 systems thinking | 单一原因→多元系统的分析框架（官网有专页；页码待核实） | 与「找系统」割裂——两者是一件事的两面 |
| 合理怀疑指南 reasonable doubt | 对不同数据源分级怀疑、按来源加权（官网专页） | 怀疑一切=虚无主义；实为分级加权 |
| Dollar Street | 安娜的项目：按收入等级拍摄全球家庭日常，照片当数据 | 旅游摄影；实为数据工具 |

## 证据锚（引用时保留语境，勿夸大）

1. **GMS 2017**（核心证据锚）：12 道三选一全球事实题，14 个富国在线面板（Novus 挪威 n=1221、芬兰 n=1000；Ipsos MORI 12 国 n=10,024，2017-07/08），加权抽样。人类平均 **2.2/12** < 随机 4/12；仅 10% 优于随机；**15% 全错**（随机几乎不可能，证明系统性错误知识）；气候题 87% 答对被剔除。局限：仅富国、在线面板、个别译本题面有误（官方勘误记载）。
2. **13 题自测**（答案经官方逐题核实，书中题序待核实）：极端贫困近 20 年几乎减半（World Bank）；一岁儿童接种 80%（WHO/UNICEF）；自然灾害死亡百年降到不足一半（OFDA/CRED）；多数人住中等收入国家 76%（World Bank）；30 岁男女受教育 10 vs 9 年（IHME）；2100 年增 40 亿主因是更多成年人（UN 2015 WPP）；低收入国家女童小学毕业 60%（实际 63.2% 2015，取整避免夸大）；0–15 岁儿童 2100 年仍 20 亿（UN）；预期寿命 70（IHME 72.48/UNPop 71.9）；用电人口 80%；老虎/大熊猫/黑犀牛均未更濒危（IUCN，熊猫 2015 EN→VU）。
3. **官方勘误页 30+ 处**：p.37「>$64」→「>$32」；「民主改善」图因近十年民主质量下降被撤换为奥运参赛队图；五张图 194→195；p.216–218 一胎化段落重写——「从六到三的下降发生在政策前十年；政策 36 年间从未低于 1.5；那甚至不是毛泽东的政策，是去世后推出」；p.271 附录答案图误印「more than doubled」应为「decreased to less than half」。**这是「数据会错、勘误即行动」的机构级示范。**
4. **伊朗生育率骤降**：文化可快速变化的例证（Gapminder 有专页；书中数字待核实）。
5. **美国卫生支出第一 vs 预期寿命约第 40**：单一指标会骗人（豆瓣简介逐字核实；年份待核实）。
6. **中国一胎化政策**（第 9 章，勘误后文本）：归咎本能与单因叙事的反例——生育率下降先于政策。
7. **Bill Gates 赠书**：2018 年向全美应届毕业生免费赠电子版；评「我读过的最重要的书之一」。出处：Gapminder 页/Columbian/WEF。
8. **FT/McKinsey 2018 商业图书奖长名单**（首本瑞典商业书）；Nature 书评《Swansong of Hans Rosling, data visionary》（Nature 556:25, 2018）；Obama 2018 夏季书单；Pinker《卫报》推荐。
9. **TED 演讲生涯**：2006 年《The Best Stats You've Ever Seen》用气泡图成名，后续 2010《The Magic Washing Machine》、2014 与欧拉合讲《How Not to Be Ignorant About the World》——13 题测试的现场版（标题级核实，细节待核实）。
10. **GMS 2017 方法细节**：Novus（挪威 n=1221、芬兰 n=1000）+ Ipsos MORI（12 国 n=10,024，18–64/16–64 岁，2017-07-25 至 08-06，加权；n=1000 时误差约 ±3.1pp）。局限：仅富国、在线面板。

## 可操作原则（书中证据推出）

1. 引用数据先答口径四件套：来源/年份/定义/基准。
2. 只对有强证据的观点持有意见；没有证据说「我不知道」。
3. 水平与趋势分开报告，两栏都写。
4. 预期坏消息：默认直觉低估进步，读坏消息查反向数据。
5. 外推前先问曲线形状（S/滑梯/驼峰/倍增），不默认直线。
6. 风险=危险×暴露；恐惧主题做分解表；恐慌中不做重大决定。
7. 大数字先除法：人均/比率/80-20/对比锚。
8. 质疑分类：组内差异+组间相似；生动特例标注典型性。
9. 数据有年份；>3 年先更新；引用标「截至」。
10. 每个结论找反证与替代指标；专家与数据分开标注。
11. 归因用系统因素清单，坏人/英雄改写为原因链。
12. 紧急时小步：要数据→分真伪→最小一步→评估放大；真紧迫清单=五大全球风险。

## 批评与边界（引用时的红线）

1. 粉饰批评：进步叙事被批淡化苦难与分配——豆瓣高赞「数据也是会骗人的」；Christian Berggren 曾批评统计口径（具体文章待核实）。
2. 乐观 ≠ 无行动：五大全球风险是书内行动清单；「世界在变好」不是「什么都不用做」的凭据。
3. 数据会错会过时：勘误 30+ 处、阈值三度修订、民主图撤换；2019 年后疫情/民主倒退/寿命回落已改变部分趋势——引用必带年份。
4. 「水平-趋势」不可互为挡箭牌；两栏都写，决策面对真实水平。
5. 平均值掩盖分布（书中钟形曲线警告）；总体改善 ≠ 人人改善。
6. 相关 ≠ 因果；书中关联保持「关联/趋势」措辞。
7. 中文译名风险：「一分为二」是辩证法术语（多褒义），2019 版用它译 gap instinct 易误读；skill 须附英文原词。
8. 鸡汤化风险：中文营销压缩成「远离焦虑、变得乐观」；真正载荷是口径纪律与更新机制。
9. 黑猩猩比喻是修辞：证明「错误世界观」非智力差异，勿猎奇化。
10. 证据等级有限：测试是富国在线面板的横截面证据，「证据锚」非「定律」。
11. 数据时效红线：书中数据截至 2016–2017；引用必带年份并查最新值（官方勘误页即「数据会过时」的自证）。
12. 分类标签会变：「发达/发展中」二分已被机构逐步弃用（世界银行 2016 年 WDI 起，精确表述待核实）——skill 引用任何分类标签都要查当年口径。

## 对 agent 工作的映射

1. 引用统计 → 自动附口径四件套（来源·年份·定义·基准），缺一标「待核实」。
2. 记忆数字 → 显式「记忆值」+ 检索更新；训练数据里的世界是旧世界。
3. 情绪化断言（崩溃/完蛋）→ 不接情绪，给水平+趋势双栏数据。
4. 风险/灾难主题 → 危险×暴露表 + 同量级参照基准。
5. 「必须立刻」→ 降速协议：要数据、分真伪、小步、评估。
6. 趋势预测 → 声明曲线假设，不默认线性。
7. 单一结论 → 强制反证搜索 + 替代指标。
8. 归因 → 系统因素清单替代坏人/英雄叙事。
9. 转述研究 → 一手来源；二手降级标注。
10. 自己引错 → 显式勘误，不静默修改（官方先例）。
11. 任务过载/专注排程 → 转 `bandwidth-and-deep-work`（交叉引用，规范 §8）。
