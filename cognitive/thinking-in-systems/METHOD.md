# METHOD：`thinking-in-systems` 这本书是怎么被转化成 skill 的

> 本文件记录《系统之美：决策者的系统思考》（Donella H. Meadows，2008；中文版邱昭良译，浙江教育出版社 2023）→ `thinking-in-systems` 的具体转化过程。格式参照 `.dsh/skills/book-to-skill/METHOD.md`。

---

## 一、这本书为什么适合 / 核心判断

**作者在跟谁争论**：跟「头痛医头」的干预习惯争论——政客调参数、管理者换人加力度、KPI 信徒堆指标，全在结构的最浅层用力。核心判断：**系统的行为由结构（存量、流量、反馈回路、延迟、非线性）产生，不由单个要素或人的意图产生**；干预的关键是识别结构与杠杆点层级，且「层级越高，杠杆越大，系统抵制越强」。

适合做成 skill 的原因：①概念全部可操作化（存量流量图、R/B 回路、12 杠杆点层级都是可执行的判定步骤）；②自带诊断对象（8 大陷阱 = 8 个可匹配的症状表）；③作者本人给出批评边界（模型≠现实、清单不是配方），天然满足诚实红线。

## 二、分离出的 10 条核心准则（if-then）

| # | 当 X 时 → 做 Y | 对应处方 |
|---|---|---|
| 1 | 当用户问「为什么越改越糟」时 → 先画存量流量图与回路，不先谈人 | 问 1–2 |
| 2 | 当发现自我加强趋势时 → 判 R 回路并找「什么会耗尽」装制约 | A1 |
| 3 | 当出现震荡/过冲时 → 先查三段延迟与信息时效，再谈力度 | A2 |
| 4 | 当干预停在参数层无效时 → 上移到信息流（第 6 层）/规则（第 5 层） | A3 |
| 5 | 当标准被悄悄下调时 → 报目标侵蚀，标准写成绝对量 | B3 |
| 6 | 当多角色互相对拉时 → 报政策阻力，停止加力、对齐共同目标 | B1 |
| 7 | 当依赖外部救火加深时 → 报转嫁负担，能力建设与救火并行 | B5 |
| 8 | 当资源按当前成绩再分配时 → 报富者愈富，装平权机制 | B6 |
| 9 | 当指标全绿结果难看时 → 报规避规则/目标错位，改成果指标 | B4 |
| 10 | 当输出诊断结论时 → 附「这是一个模型」声明（假设/边界/反例） | C2 |

## 四、失败/风险记录

1. 审查发现 4 处数字/层号失准（「九成」无笔记支撑、Forrester 引语未逐字核实、A6 层号错、「上移一层」跳层）——已修复，教训：**铁律与处方里任何数字/引语/层号都必须能在 notes 中找到出处**。
2. description 触发词「系统性问题怎么办」有 IT 歧义——已加「（组织/流程/指标层面的）」限定并在「不适用」豁免 IT 排障，教训：中文触发词要过一遍领域歧义检查。
3. 遗留待核实：书内页码、中文第 2–7 章标题、电表 30% 原始出处、「15 vs 14」法则计数——均已显式标注，核书后回填。
4. 书是遗作手稿，结构松散（读者共识批评）——skill 自己拧紧了五问流程，未照搬原书结构。
