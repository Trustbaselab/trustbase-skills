# METHOD · 把一本好书变成 agent skill 的方法（v1）

> 做出一个 skill 是一次性的；做出「造 skill 的方法」才是可复用资产。
> 本方法由「《稀缺》+《深度工作》→ `bandwidth-and-deep-work`」这次实践总结而来，适用于下一本书。
> License：Apache-2.0（本文为 Trustbase Lab 自有方法论，非任何书籍内容的复述）。

---

## 六步法

| # | 步骤 | 关键要求 | 本次实践对应物 |
|---|---|---|---|
| **1** | **读透** | 不是做摘要，是找出这本书的**核心判断**（作者在主张什么、论证链是什么、证据是什么级别） | `_book-research/scarcity-notes.md` 与 `_book-research/deep-work-notes.md`（§1 一句话论点 + §2 论证链 + §4 证据） |
| **2** | ⭐ **分离「道理」与「准则」** | 「道理」读时点头、无法检验；「准则」能变成**可检验的行为规则**。只把「准则」带进 skill | 概念词典里每条都区分「书中原意 vs 常见误解」；只把可操作原则写入处方库 |
| **3** | ⭐ **翻译成 agent 规则** | 一律 **if-then 形式**：「当 X 时，做 Y」。⛔ 不接受「要专注」「要留缓冲」这种空话 | 如：「当任务 >1 且都紧急时 → 先归档/搁置到只剩一个主目标」「当回合结束时 → 写关机记录」 |
| **4** | ⭐⭐ **在真实场景验证** | 必须至少有**一处真实应用 + 前后数据**；没有验证数据的概念不进 skill 的「证据」区 | `references/evidence.md`：DSH-INBOX 565.6KB→26.8KB、每轮 141K→5.6K tokens、状态查询 2–3 分钟→5 秒 |
| **5** | ⭐ **记录验证数据** | 前后对比、**可复算**（文件路径、口径、测量方法）、诚实标注估算项与口径差异 | evidence.md 的「数据口径与诚实边界」小节 |
| **6** | **写成 SKILL.md** | 必须含：**触发条件**（用户会说的原话）/ **行为规则**（if-then）/ **反例与边界**（何时不适用、常见误用）/ **来源标注**（书目+页码/DOI）/ **版权边界** | 本 skill 的「何时使用 / 三条铁律 / 诊断三问 / 处方库 / 边界与常见误用 / 参考文件」 |

## 版权边界（⛔ 红线）

- ⛔ **不抄原文段落**：引用以短引文 + 出处为限，不搬运大段内容。
- ✅ **注明「基于《书名》的理念（作者，年份）」**：skill 的定位是「书的理念 → agent 行为规则的翻译」，不是书的替代品。
- ✅ **我们的贡献** = 翻译成 agent 规则 + 项目验证数据 + 方法论，这部分自有权，License 用 **Apache-2.0**。
- ✅ **保留批评视角**：每本书的概念都附带「常见误用与批评边界」，防止 skill 变成成功学复读机。

## 产出结构（每个 skill 目录）

```
<skill-name>/
├── SKILL.md                  # 触发条件 + 铁律 + 诊断流程 + 处方 + agent 协议 + 边界
├── METHOD.md                 # 本文件（做完第三本书后抽出为 cognitive/METHOD.md 元方法）
└── references/
    ├── <book>-book.md        # 全书笔记：概念词典（原意+误解）、证据锚、引文、批评
    └── evidence.md           # 我们的验证数据：问题→概念→做法→前后量化结果
```

## 质量红线（做完必自查）

1. **概念精确到书中原意**，不能拿日常比喻冒充定义（如「带宽」≠「精力」）。
2. **证据分级表述**：「证据锚」≠「定律」；实验的局限、复制争议必须写明。
3. **待核实 = 待核实**：没核到原文的数字一律标注，不能写成像核实过的一样。
4. **有反例有边界**：写清「何时不适用」，比写清「何时适用」更防误用。
5. **description 可触发**：触发词要用用户会说的原话，而不是学术术语。

---

## 迭代规则

- 前两本书：METHOD.md 随 skill 存放（当前状态）。
- **第三本书之后**：把 METHOD.md 提升为 `cognitive/METHOD.md`（元方法），每做一本就修订一次。
- 每本书的 skill 目录命名：以**核心概念**命名（当前：`bandwidth-and-deep-work`），书目标注在 description 与 references 内。
