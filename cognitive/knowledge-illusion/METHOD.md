# METHOD · 《知识的错觉》→ knowledge-illusion 转化记录

> 本书的 skill 转化记录（book-to-skill 七步法的第 6 步产物）。转化日期：2026-10-18。License：Apache-2.0。

## ① 为什么这本书适合做 skill / 核心判断

- **核心判断**：作者在跟「理性个体」神话争论——个体头脑里的理解极浅，知识栖居在共同体中；智能 ≈ 对集体思考的贡献。
- **适合理由**：书的核心发现可直接翻译成 agent 的可执行纪律——「记得≠核验过」「流畅≠懂」「检索≠内化」，正好治理 AI 最核心的缺陷（把检索到/讲得顺误当真懂）。选书评分 4.45（①立场5 ②if-then4 ③同源5 ④验证4）。

## ② 分离出的核心 if-then 准则（SKILL.md 处方库 K1–K8）

1. 当输出事实性主张时 → 标注知识状态（记忆/已核验/检索）与来源；无来源 → 「未核验/待核实」。
2. 当被要求解释机制时 → 先自测 3 步因果链；写不出 → 声明理解层级并检索，不编因果故事。
3. 当结论仅由单一来源支撑时 → 强制交叉第二独立来源；无法交叉 → 降置信。
4. 当刚完成检索/读文档后 → 执行「检索≠内化」自查，输出标注「检索所得」。
5. 当对方立场极端且拒绝事实时 → 用解释测试代替灌信息（仅当对方愿意配合）。
6. 当用户质疑依据时 → 出「主张-证据-置信度卡」，置信度只按可核验证据赋值。
7. 当引用共同体知识时 → 写「转述自 X（年份），我未独立核验」。
8. 当评估理解程度时 → 用四阶梯（听说/会用/能解释/能预测边界）提问，拒绝二分自评。

（配套 agent 协议 6 条见 SKILL.md「Agent 执行协议」。）
